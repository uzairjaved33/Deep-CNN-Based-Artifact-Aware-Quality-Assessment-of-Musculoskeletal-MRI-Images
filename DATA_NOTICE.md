# Data Notice

This repository intentionally does not include the KMAR-50K MRI dataset, raw NIfTI files, preprocessed caches, validation caches, prediction caches, or trained checkpoint binaries.

Excluded items include:

- ArtifactData_part1/
- GroundTruthData_part1/
- Testing _GroundTruthData/
- TrainingCohort.csv
- TestingCohort.csv
- preprocessed_cache/
- val_cache/
- *.nii / *.nii.gz
- *.pt / *.pth / *.pkl model artifacts
- checkpoints/prediction_cache/
- samples_ssim_labeled.json
- test_samples.json
- test_samples_ssim.json

The repository contains code, documentation, generated research plots, lightweight metrics, final evaluation reports, and reproducibility scripts only.
